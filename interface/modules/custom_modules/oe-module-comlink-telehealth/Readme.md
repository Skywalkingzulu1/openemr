### Comlink Telehealth Module

This project implements the Comlink Telehealth system for video conferencing for DCL installations.

The instructions for using this module can be found on the DCL Wiki page here [Comlink Telehealth Technical Guide](https://www.dcl.org/wiki/index.php/Comlink_Telehealth)
